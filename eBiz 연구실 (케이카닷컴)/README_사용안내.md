## 새 목업·보고서 올리는 방법
1. **내 PC에서 올리기**
   - 이 `eBiz 연구실 (케이카닷컴)` 폴더 안에 원하는 파일(`.html`, `.pdf`, `.csv`, `.xlsx`, `.png` 등)을 복사해 넣습니다.
   - 상위 폴더(`SUMMARY`)에 있는 **`깃허브_업로드.bat`** 을 더블클릭합니다.
   - 업로드 완료 후 내 PC를 꺼도(OFF) 언제 어디서나 GitHub Pages 웹 주소로 접속해 열람할 수 있습니다.

2. **PC가 꺼져 있을 때 웹/모바일에서 바로 올리기**
   - GitHub 저장소의 `eBiz 연구실 (케이카닷컴)/` 폴더에서 `Add file > Upload files`로 파일을 올리면, 연구실 페이지가 실시간으로 새 파일을 감지해 목록에 자동 표시합니다.
